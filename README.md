# Customer Sentiment Analysis

This project builds and evaluates machine learning and deep learning models to classify customer sentiment (positive or negative) from text reviews.

## 🚀 Overview

- Preprocess customer review data (cleaning, lemmatization, TF-IDF, tokenization)
- Train and evaluate models:
  - Logistic Regression
  - Random Forest
  - XGBoost
  - LSTM / GRU with Keras
- Perform hyperparameter tuning using Keras Tuner
- Explain predictions using SHAP visualizations

## 📦 Tools & Libraries

- Python, pandas, scikit-learn
- Keras, TensorFlow
- XGBoost, LightGBM
- SHAP, seaborn, matplotlib
